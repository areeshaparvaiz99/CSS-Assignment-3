CSS: Cascading Style Sheets

Cascading Style Sheets (CSS) is a stylesheet language used to describe presentation of a document written in HTML or XML. CSS describes how elements should be rendered on screen, on paper, in speech.


CSS is among core languages of open web and is standardized across Web browsers according to W3C specifications. You might have heard about CSS1, CSS2.1, CSS3. There will never be CSS4; rather everything is now just CSS with individual modules having version numbers.
